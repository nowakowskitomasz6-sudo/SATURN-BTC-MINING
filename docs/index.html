☝️ Jak działa SATURN?

Projekt ma łączyć społeczność górników Bitcoin SOLO. Samo zgłoszenie nie zmienia ustawień koparki, nie łączy mocy i nie uruchamia podziału nagród. Zasady uczestnictwa i ewentualnych wypłat muszą zostać odrębnie określone i zaakceptowane.

Wydobywanie SOLO jest losowe — nie ma gwarancji znalezienia bloku ani wypłaty.
